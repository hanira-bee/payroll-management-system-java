# Employee Salary Calculation Application (Java Swing GUI)

A simple desktop application built with Java Swing to simulate the calculation of employee salary components—ranging from gross income and mandatory deductions to the final net salary received. This project was created using **Apache NetBeans IDE**.

## 🚀 Key Features
* **Employee Data Input:** Enter Employee Code, Name, Gender (Male/Female), and Date of Birth.
* **Income Calculation:** Input Base Salary, Allowances, and Overtime Pay; automatic calculation of Total Income.
* **Deduction Calculation:** Input BPJS (social security) costs and Taxes; automatic calculation of Total Deductions.
* **Summary Output:** Displays a detailed salary slip/breakdown in the text area after clicking the "Calculate" button.

## 🛠️ Prerequisites & Environment
* **Java Development Kit (JDK):** Version 17 or later (OpenJDK recommended).
* **IDE:** Apache NetBeans (Recommended, as it utilizes the NetBeans GUI Builder feature).

## 🏃 How to Run the Project
1. Clone this repository to your computer:
```bash
git clone https://github.com
```
2. Open **Apache NetBeans**.
3. Select **File > Open Project**, then navigate to this project's folder.
4. Locate the `AFrame.java` file within the `GajiKaryawan` package.
5. Right-click the file and select **Run File** (or press `Shift + F6`).
